# Reinforcement-Learning
The projects of the course "EECE-5614: Reinforcement Learning and Decision Making Under Uncertainty" are gathered.
The course syllabus includes:
* Preliminaries
    * Multi-Armed Bandit
    * Bellman Equation and Optimality
* Dynamic Programming (DP)
    * Value iteration (Matrix Form)
    * Policy Iteration (Matrix Form)
    * Approximate DP
* Temporal Difference (TD) Learning
    * SARSA
    * Q-Learning
    * Tabular Actor-Critic
    * On-policy vs. Off-policy
* Deep Q-Network (DQN)
    * Double DQN
    * Dueling DQN
